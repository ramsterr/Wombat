# The Way of Learning

An eighty-one-chapter interactive book about machine learning, written after
Lao Tzu. Each chapter pairs a short verse with a canvas artifact you can touch,
tune, and reshape.

Open `index.html` directly, or serve the folder:

```sh
python3 -m http.server 8080
```

Then visit <http://localhost:8080>. No build step or dependencies are required.
The screenshots in `screenshots/` record several of the chapter artifacts.
