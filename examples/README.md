# Examples

Reference tasks and outputs, grouped by genre. Genre folders marked only by
`.gitkeep` are placeholders for future examples.

| group | genres |
|---|---|
| build & code | `backend`, `frontend`, `mobile`, `cli-tools`, `games`, `embedded`, `databases`, `api-integration`, `cloud`, `devops` |
| data & ai | `data-analysis`, `data-viz`, `machine-learning`, `simulations`, `research` |
| web & automation | `scraping`, `browser-use`, `automation`, `macos` |
| creative | `design`, `image-generation`, `audio`, `music`, `video`, `3d-modeling`, `writing` |
| quality & ops | `testing`, `debugging`, `performance`, `security`, `code-review`, `refactoring`, `documentation`, `monitoring`, `networking` |
| other | `accessibility`, `education`, `finance` |

## Included examples

- `data-viz/nash-equilibrium` — single-file interactive Prisoner's Dilemma
  explainer, plus result screenshots from issue #13.
- `data-viz/music-chart` — Billboard year-end artist chart for 2024–2025.
- `design/cat` — SVG cat illustration and rendered PNG.
