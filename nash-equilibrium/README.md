# Nash Equilibrium — Interactive Visual

Open `index.html` in any browser (no server needed). A lightweight, single-file interactive explainer.

## What it shows
- **Payoff matrix** for the classic 2-player Prisoner's Dilemma with live NE highlighting.
- **Sliders** for R (reward), T (temptation), S (sucker), P (punishment), plus each player's mixed strategy probability.
- **Best-response diagram** showing where the mixed-strategy Nash Equilibrium sits (green dot).
- Theory notes: definition, PD ordering T>R>P>S, mixed strategies, existence theorem.

## Theory (short)
A Nash Equilibrium is a strategy profile where no player can improve their payoff by unilaterally changing strategy — each plays a best response to the others. In PD, (Defect, Defect) is the unique NE despite (Cooperate, Cooperate) being Pareto-superior. Nash proved every finite game has at least one NE (possibly mixed).
